# Smart-SME-Bank-Statement-Analyzer
An SME bank statement categorization and cash-flow stress simulation dashboard using Python, Streamlit, LangGraph and LangChain.

Problem Statement

Pension fraud and eligibility violations lead to financial losses.
Manual verification is time-consuming and error-prone.
Need an intelligent system to detect suspicious pension claims early.

Solution

AI-driven pension claim analysis platform.
Fraud detection using Machine Learning.
Risk scoring and anomaly detection.
Interactive dashboard for investigation.

Business Impact

Faster claim verification.
Reduced fraud losses.
Improved operational efficiency.


Dashboard Outputs

Total Pension Records
High-Risk Cases
Fraud Probability Score
Region-wise Analysis
Risk Distribution Charts

Unique Features ✅ AI Fraud Risk Score

✅ LangGraph Decision Flow

✅ Automated Investigation Recommendations

✅ Smart Pension Health Index

✅ Explainable AI Insights

Project Outcome

Detect suspicious pension claims automatically.
Prioritize high-risk beneficiaries.
Support auditors with data-driven decisions.
